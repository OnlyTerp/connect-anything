Let the coding agent you’re in ask your other agents, each through its official CLI on your own sign-in. Pick your agents, connect your apps and try a call. When you ask an agent, your prompt goes to that agent’s vendor, as if you ran its CLI yourself.

    4Cloud assistants preview
    
    
    Assistants that live in the cloud (ChatGPT, claude.ai, phone apps) can reach these tools over HTTP. Keep that address private.
    
    
      
      
    1. Run connect-anything serve (this page's server already does).
      2. 
      
    2. Expose it with a tunnel you trust, e.g. cloudflared tunnel --url http://127.0.0.1:7777. Then restart with --public-host <your-tunnel-host>.
      3. 
      
    3. Add an MCP connector in your assistant with the URL https://<your-tunnel-host>/mcp/<token>.
      4. 
    
    
    
    Over HTTP, agents are read-only, limited to the folders in settings.httpRoots, and can't start cloud agents, unless you start serve with --allow-write / --allow-cloud.
